rememberVgsTextState

@Composable
fun rememberVgsTextState(show: VGSShow, contentPath: String, ignore: Boolean = false, visualTransformation: VgsVisualTransformation = VgsVisualTransformation.None): MutableState<VgsTextState>

Creates and remembers text reveal state for use with VgsText.

Call this once per text field, inside the composable that will display it. show takes care of subscribing and unsubscribing this state automatically as the composable enters and leaves the screen — you don't need to call VGSShow.subscribe / VGSShow.unsubscribe yourself. Once you call VGSShow.request or VGSShow.requestAsync, the returned state updates automatically and VgsText recomposes with the revealed text.

Return

State to pass to VgsText via .value.

Parameters

show

The VGSShow instance this field belongs to.

contentPath

The path of the value to reveal in the response, e.g. "json.my_data".

ignore

Set to true to exclude this field from reveal requests (e.g. to temporarily hide it) without unsubscribing it.

visualTransformation

Optional VgsVisualTransformation applied to the revealed text, e.g. to mask part of it. Applied once per revealed value, not on every recomposition.
