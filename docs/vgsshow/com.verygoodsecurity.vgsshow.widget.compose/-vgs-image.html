VgsImage

@Composable
fun VgsImage(state: VgsImageState, contentDescription: String?, modifier: Modifier = Modifier, alignment: Alignment = Alignment.Center, contentScale: ContentScale = ContentScale.Fit, alpha: Float = DefaultAlpha, colorFilter: ColorFilter? = null)

Securely displays a revealed image.

Draws nothing until an image has been revealed and decoded. To show your own loading or error UI, branch on state — VgsImageState.hasImage is true once data has arrived, and VgsImageState.isImageValid is true only if it decoded successfully:

val imageState = rememberVgsImageState(show = vgsShow, contentPath = "json.my_image")
if (imageState.value.isImageValid) {
    VgsImage(state = imageState.value, contentDescription = "ID scan")
} else {
    CircularProgressIndicator()
}
